# ReadGlass Android

Floating bubble companion (same idea as Tracker Voice).

## Build

```bash
flutter pub get
flutter build apk --release
```

APK: `build/app/outputs/flutter-apk/app-release.apk`

## Use

1. Install APK
2. Open app → enable Floating bubble → allow “Display over other apps”
3. Open book in Chrome
4. Tap Listen on the bubble
